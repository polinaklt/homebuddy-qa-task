# Regression Test Suite Structure

| # | Module | What is covered |
|---|---|---|
| 1 | Landing page | Content and typos, three ZIP forms, photo gallery, reviews carousel and links, footer |
| 2 | ZIP validation and service area | Format, in-area and out-of-area ZIPs, "no matching contractors" screen |
| 3 | Wizard navigation | "Next", Close (X), Back, Cancel |
| 4 | Wizard steps | Each question: kitchen elements, cabinets work type (conditional), property type, home type, homeowner, kitchen size, budget |
| 5 | Warning flows | Commercial, mobile home, not homeowner, low budget, "No" home type, "Yes" homeowner |
| 6 | Contact data | Full name and email validation, phone format and mask, phone check and confirmation screen, duplicate phone + email |
| 7 | Submission and thank-you page | Final submit, submit fail, thank-you page content, lead status |
| 8 | API and data integrity | Payloads match the answers, error handling |
| 9 | Legal pages and consent | Privacy Policy, Terms of Use, consent text on the phone and email steps |
| 10 | Cross-browser and mobile | Chrome, Safari, Firefox, mobile viewport |
| 11 | Accessibility | Keyboard navigation, labels and alt text |
